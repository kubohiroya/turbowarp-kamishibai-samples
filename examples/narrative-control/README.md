# 三人の訪問

この開発例はDSL 4.0 RCの標準サンプルへ移りました。
正本・素材・再生成手順は[stories/three-visits](../../stories/three-visits/README.md)、
配布物は[公開ページ](https://kubohiroya.github.io/turbowarp-kamishibai-samples/stories/three-visits/)を参照してください。
最初の対応版はApp 4.0.0-rc.44です。4.1系列は新設せず、通常のCLIに追加の実験flagは不要です。
旧4.1開発形式は原本を保管し、YAMLの4.0宣言を検証して対応版で再生成します。npm公開とは別の配布です。
