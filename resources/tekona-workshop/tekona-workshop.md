# 手児奈にプロポーズ！ AIと演じる参加型紙芝居

〜 国府台・真間の伝承「手児奈」を、みんなで新しくつくろう（40分）〜

# 0. この時間にすること

むかし、市川市の真間に「手児奈（てこな）」という娘がいました。
あまりの美しさに、里の若者も、国府の役人も、都の貴族も、つぎつぎと求婚にやってきます。

今日は、みなさんが**手児奈に求婚する男たち**になりきります。

1. カメラの前で、求婚者になりきって**決めポーズ**をキメます。
2. **ポーズ認識AI**が、そのポーズを見分けます。
3. ポーズが決まると、求婚者が求婚の言葉を言い……AI紙芝居の手児奈に**ことわられます**。

そして今日のメインは、**みんなのアイデアで「4人目の求婚者」をつくること**です。
キャラクター・決めポーズ・セリフを考え、AIにそのポーズを覚えさせて、紙芝居に登場させます。

> ⭐️ 撮影した写真は、AIにポーズを覚えさせるためだけに使います。体験会が終わったら削除します。
> 写りたくない人は、撮影のときに無理に写らなくてかまいません。スタッフに声をかけてください。

# 1. 紙芝居を体験しよう（約6分）

前のスクリーンで、紙芝居「手児奈 ― 真間の井の求婚者たち」を上演します。
求婚者が出てきたら、代表の人がカメラの前に立って、その求婚者の決めポーズをとってみましょう。

| 求婚者 | 決めポーズ |
| --- | --- |
| 里の若者 | 両うでで、頭の上に大きなハート |
| 国府の役人 | 片手を胸に当てて、もう片方の手をさしだす |
| 都の貴族 | 両うでを、横に大きく広げる |

画面に「ポーズをキメよう！」と出たら、ポーズをとったまま、少しだけじっとしていてください。
AIがポーズを見分けると、物語が進みます。

> ⚠️ ポーズをとるときは、まわりの人や物にぶつからないように気をつけてください。

# 2. 4人目の求婚者を考えよう（約7分）

紙芝居の求婚者は、まだ3人しかいません。みんなで**4人目**を考えましょう。
下の「求婚者づくりシート」を使って、アイデアを出してください。いちばん人気のアイデアを採用します。

## 求婚者づくりシート

手児奈が生きたのは、1300年以上前。都から役人が来て、真間のそばの国府台に国の役所（国府）がありました。
その時代、その土地に、どんな男の人がいたでしょう？

| 考えること | ヒント | あなたのアイデア |
| --- | --- | --- |
| 1. 身分・職業 | 入江の漁師、機織りの名人、歌の上手な若者、郡司（土地の有力者）の息子…… | |
| 2. 人物特性・表情 | 元気？ まじめ？ いばりや？ ロマンチスト？ どんな顔で求婚する？ | |
| 3. 服装・髪型・装身具 | 布は麻？ 絹？ 色は？（むかしは身分で着られる色が決まっていました） 持ち物は？ | |
| 4. 演技・セリフ | 決めポーズ、求婚の言葉、手児奈のことわりの言葉。手児奈の心は、ちょっとゆれた？ | |
| 5. 立ち絵・ポーズ・表情のバリエーション | ふつうに立つ絵、決めポーズの絵、ことわられたときの顔 | |

時代劇やまんがで見る烏帽子やちょんまげは、もっと後の時代のものです。
時代や土地をくわしく調べてからつくる場合は、[`research-worksheet.md`](research-worksheet.md)を使います。

## 決めポーズの注意

AIが見分けやすいポーズにするために、次のことに気をつけましょう。

* **上半身だけで分かる**ポーズにします。足だけがちがうポーズは、カメラに写りにくく見分けられません。
* ほかの3人のポーズ（ハート・胸と手・両うでを広げる）や、ただ立っている「気をつけ」と、**はっきりちがう**ポーズにします。
* うでの角度、ひじを曲げるか伸ばすか、手の高さを変えると、ちがいがはっきりします。
* だれでもすぐにまねできて、**数秒そのまま止まっていられる**ポーズにします。

# 3. 4人目の絵をつくろう（約5分）

みんなのアイデアをもとに、講師がその場で4人目の立ち絵とポーズ絵をかきます。
「服は何色？」「ぼうしは？」「何を持っている？」と聞くので、どんどん声をかけてください。

# 4. AIにポーズを覚えさせよう（約10分）

Googleの「Teachable Machine」を使って、ポーズ認識AIに4人目の決めポーズを覚えさせます。

1. AIはすでに、「気をつけ」と3人の求婚者のポーズを覚えています。
2. そこに、新しいポーズ「new」を加えます。
3. 何人かの人が交代でカメラの前に立ち、4人目の決めポーズをとります。そのあいだに、AIのための「サンプル」の写真を撮ります。
4. 写真がそろったら、AIに「トレーニング（学習）」をさせます。
5. 最後に、ポーズをとってみて、AIがちゃんと見分けられるか確かめます。

## 撮影のコツ

* いろいろな人（背の高さ・服のちがう人）が写ると、AIはだれのポーズでも見分けられるようになります。
* 同じポーズのまま、少し前後に動いたり、うでの角度をほんの少し変えたりすると、よいサンプルになります。
* カメラに**頭から腰まで**が写るように立ちます。
* 撮影している人のうしろに、ほかの人が写りこまないようにします。

## 考えてみよう

* サンプルの写真が少なすぎると、AIはどうなるでしょう？
* 同じような写真ばかりだと、AIはどうなるでしょう？
* AIが覚えたのは「写真」そのものでしょうか？ それとも、写真の中の「体のかたち」でしょうか？

# 5. みんなで上演しよう（約5分）

講師が紙芝居の台本に、4人目の求婚者と、いま学習させたAIを加えます。
もう一度、最初から上演しましょう。4人目の求婚者が出てきたら、アイデアを出した人が決めポーズをキメてください。

台本の中では、求婚者の一覧が表のように書かれています。
1行が1人の求婚者で、行を1つ足すだけで、求婚の場面がもう1回くりかえされます。

```yaml
- name: 4人目の求婚者
  pose: new
  proposal: みんなで考えた求婚の言葉
  refusal: みんなで考えた手児奈のことわりの言葉
```

# 6. まとめ（約3分）

## 本当の言い伝え

今日の紙芝居では、手児奈は「わたしの心は、わたしのもの」と自分の生き方を選び、男たちは争いをやめて入江に橋をかけました。
これは、言い伝えをもとに新しくつくった**再話**です。

言い伝えでは、手児奈は自分のために人びとが争うことを悲しみ、夕日の入江に姿を消したといわれています。
里の人びとは手児奈を真間の井のそばにまつりました。いまも市川市真間には手児奈霊堂があり、
手児奈が水をくんだという真間の井も残っています。手児奈の話は、1300年ほど前の歌集『万葉集』にもうたわれています。

## 今日やったこと

* 地域の伝承を、参加型の紙芝居として新しく語りなおしました。
* 新しい登場人物のキャラクター・ポーズ・セリフを、みんなで考えました。
* ポーズ認識AIに、新しいポーズを覚えさせました。AIは、たくさんのサンプルから「体のかたち」の特徴を学びます。
* 台本の表に1行足すだけで、物語の場面がふえることを確かめました。

## 撮影した写真について

Teachable Machineで撮影した写真は、体験会が終わったらスタッフが削除します。
紙芝居で使うAIのモデルには、写真そのものは入っていません。写真から取り出した「体のかたち」の特徴だけが入っています。
