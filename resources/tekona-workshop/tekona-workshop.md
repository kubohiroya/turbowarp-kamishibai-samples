# 手児奈にプロポーズ！ AIと演じる参加型紙芝居

〜 国府台・真間の伝承「手児奈」を、みんなで新しくつくろう（40分）〜

# 0. この時間にすること

むかし、市川市の真間に「手児奈（てこな）」という娘がいました。
あまりの美しさに、里の若者も、国府の役人も、都の貴族も、つぎつぎと求婚にやってきます。

今日は、**ひとり1人の求婚者**をつくって、みんなの紙芝居に登場させます。

1. 時代を調べて、自分の求婚者（身分・見た目・2つのポーズ・セリフ）を考えます。
2. 生成AI（Copilot）で、求婚者の3つの絵をかいてもらいます。
3. ポーズ認識AI（Teachable Machine）に、自分の3つのポーズを覚えさせます。
4. 絵とセリフとAIのリンクを掲示板に出すと、スタッフがみんなの紙芝居に組み込みます。
5. 最後に、全員の求婚者が登場する紙芝居を上演します。手児奈には……全員ことわられます！

> ⭐️ ポーズの写真は、自分のPCの中でAIに覚えさせるためだけに使います。写真は掲示板に出しません。体験会が終わったら削除します。

## 求婚者の決まり（全員同じ）

**構図**：どの求婚者も、舞台の**上手**（かみて：画面の**右**）に立ち、**下手**（しもて：画面の**左**）にいる手児奈に向かって求婚します。
絵の人物は、下手の手児奈のほう（画面の左）を向くようにします。

```text
 下手（画面の左）                    上手（画面の右）
   手児奈        ←  求婚する  ←      あなたの求婚者
```

**3つの絵と3つのポーズ**：求婚者ごとに、次の3つを同じ名前でそろえます。絵のファイル名も、ポーズ認識AIのクラス名（ラベル）も、この名前です。

| 名前（半角小文字） | 絵（ファイル名） | ポーズ（Teachable Machineのクラス） | 紙芝居で使うところ |
| --- | --- | --- | --- |
| `stand` | `stand.png`：まっすぐ立っている姿 | 気をつけ | 登場するとき |
| `kime` | `kime.png`：求婚の決めポーズ | 決めポーズ | 「カメラの前で、求婚のポーズをキメよう！」 |
| `rejected` | `rejected.png`：ことわられて、がっかりしたポーズ | がっかりのポーズ | 「ことわられた……。がっかりのポーズ！」 |

紙芝居の流れは、全員同じです：**登場（`stand`）→ 求婚のポーズ（`kime`）→ 求婚の言葉 → 手児奈がことわる → がっかりのポーズ（`rejected`）→ ひとこと**。

## あなたの席番号

席番号（2けた）：**[　　]**　← 例：7番の人は `07`

掲示板への提出と、紙芝居での場面の順番に使います。

## 使うもの（PCのブラウザのタブ）

| タブ | 使うところ |
| --- | --- |
| Web検索 | 1. 調べる |
| Microsoft 365 Copilot | 2. 絵をかいてもらう |
| Teachable Machine（ポーズ） | 3. ポーズを覚えさせる |
| 掲示板 | 4. 提出する、5. 完成した紙芝居を見る |
| TurboWarp Plus Editor | （発展）自分の場面をためす |

配布資料フォルダの`copilot`に、絵の見本`style-reference.png`（用意済みの求婚者の`stand`・`kime`・`rejected`を左からならべたもの）と、
棒人間をかく白紙`kime-draft.png`があります。

# 1. 求婚者を考えよう（約7分）

前のスクリーンで、用意してある3人の求婚者の紙芝居を見たあと、自分の4人目、5人目……の求婚者を考えます。

## 1.1 少しだけ調べる

手児奈が生きたのは、1300年以上前。都から役人が来て、真間のそばの国府台に国の役所（国府）がありました。
Web検索で、次のどれか1つを調べてみましょう。

* そのころの人は、どんな布の、どんな形の服を着ていた？（検索例：「奈良時代 服装 庶民」）
* 身分によって、着られる服の色がちがった？（検索例：「位色」）
* 真間のあたりには、どんな人がくらしていた？ 何をしていた？（検索例：「下総国府」「万葉集 手児奈」）

> ⚠️ 時代劇やまんがで見る烏帽子やちょんまげは、もっと後の時代のものです。

## 1.2 求婚者カードを書く

| 考えること | ヒント | あなたのアイデア |
| --- | --- | --- |
| 1. 身分・職業 | 入江の漁師、機織りの名人、歌の上手な若者、郡司（土地の有力者）の息子…… | |
| 2. 人物特性・表情 | 元気？ まじめ？ いばりや？ ロマンチスト？ どんな顔で求婚する？ | |
| 3. 服装・髪型・装身具 | 布は麻？ 絹？ 色は？ 持ち物は？ | |
| 4. 決めポーズ（`kime`） | 求婚するときのポーズ。下の「ポーズの注意」を読もう | |
| 5. がっかりのポーズ（`rejected`） | ことわられたときのポーズ。`kime`とも「気をつけ」とも、はっきりちがうもの | |
| 6. 求婚の言葉 | 「〇〇するから、妻になってください！」 | |
| 7. 手児奈のことわりの言葉 | やさしく、でもはっきり | |
| 8. ことわられたときのひとこと | 「とほほ……」のかわりに | |
| 9. 手児奈の心は、ちょっとゆれた？ | ゆれた／ゆれなかった | |

## 1.3 ポーズの注意

`stand`（気をつけ）・`kime`・`rejected`の3つが、AIに見分けられるようにします。

* **上半身だけで分かる**ポーズにします。足だけがちがうポーズ、しゃがむポーズは見分けられません。
* 3つのポーズが**たがいにはっきりちがう**ようにします。うでの高さ、ひじの曲げ方、頭の向きを変えると、ちがいがはっきりします。
* **左右対称**のポーズ（両うでを同じように動かす）がおすすめです。左右がちがうポーズは、カメラによって左右が反対に映り、うまく見分けられないことがあります。
* だれでもすぐにまねできて、**数秒そのまま止まっていられる**ポーズにします。
* まわりの人にぶつからない大きさにします。

## 1.4 棒人間をかく

`kime-draft.png`を右クリック →「ペイントで編集する」で開き、**左に`kime`、右に`rejected`**の棒人間を2つならべてかいて、
`draft.png`という名前で保存します。上手でなくてかまいません。うでの角度が分かれば十分です。

# 2. 生成AIに絵をかいてもらおう（約4分＋待ち時間）

> ⚠️ Copilotで作れる画像は、**1日に2枚くらい**です。1枚目で`stand`・`kime`・`rejected`の**3つをいっしょに**かいてもらい、2枚目は失敗したときの予備にします。

1. Copilotの入力欄の「＋」→「画像とファイルのアップロード」で、`style-reference.png`（絵の見本）をアップロードします。
2. もう一度「＋」から、自分でかいた`draft.png`（棒人間）をアップロードします。
3. 次の文の〔　〕を、求婚者カードの内容に書きかえて、入力欄にはりつけ、送信します。

```text
添付した1枚目の画像と同じ絵柄（太い線のない、シンプルな平面イラスト）で、
同じ人物を、同じ大きさで左から3人ならべた画像を作ってください。
左：まっすぐ立っている姿。
まんなか：添付した2枚目の棒人間の、左のポーズ（求婚の決めポーズ）。
右：添付した2枚目の棒人間の、右のポーズ（ことわられて、がっかりしたポーズ）。
3人とも、体と顔を少し画面の左に向けてください（左にいる相手に話しかけているように）。
人物：〔身分・職業〕。〔人物特性・表情〕。〔服装・髪型・装身具〕。
時代は奈良時代、場所は下総国（いまの千葉県市川市）です。
頭から足まで全身を入れ、3人が重ならないようにしてください。文字は入れないでください。
背景は #00FF00 の緑一色で塗りつぶしてください。
```

4. 絵ができるまで数分かかります。**待っているあいだに、3. のポーズ学習を始めましょう。**

**うまくいかないとき**：2枚目で、文を少し変えてもう一度お願いします。2枚とも使えなかったら、スタッフに声をかけてください。
用意してある「？」の人物の絵で、セリフとポーズだけ自分の求婚者にすることもできます。

# 3. AIに自分の3つのポーズを覚えさせよう（約10分）

Teachable Machineの「ポーズ」のタブを使います。

1. クラスのラベルを、上から **`stand`**・**`kime`**・**`rejected`** にします。「Class 1」を`stand`、「Class 2」を`kime`に変え、
   「＋ クラスを追加」で3つ目を作って`rejected`にします（半角小文字。この3つの名前は全員同じです）。
2. `stand`の「ウェブカメラ」を押し、カメラに**頭から腰まで**映る位置で「気をつけ」をします。
   「長押しして録画」を押したまま、少しだけ体をゆらしながら**30〜50枚**撮ります。
3. `kime`で、求婚の決めポーズを**30〜50枚**撮ります。うでの角度をほんの少し変えたり、前後に半歩動いたりすると、よいサンプルになります。
4. `rejected`で、がっかりのポーズを**30〜50枚**撮ります。
5. 関節の丸と線（ボーン）が出ていない写真や、ほかの人が写った写真は、ごみ箱のアイコンで消します。
6. 「モデルをトレーニングする」を押して待ちます。
7. 「プレビュー」で、3つのポーズを順にとって、それぞれ正しいクラスのグラフが伸びるか確かめます。うまくいかなければ写真を足して、もう一度トレーニングします。
8. 「モデルをエクスポートする」→「アップロード（共有可能なリンク）」→「モデルをアップロード」を押します。
   「クラウドモデルは最新です」と出たら、共有可能なリンクの右の「コピー」を押します。

**ブロック台本版で行う場合**：最初に「ファイルからプロジェクトを開く」で、配布資料フォルダの`seat-NN.tm`（自分の席番号）を開きます。
クラスは`stand`・`kime`・`rejected`がすでにあります。`kime`と`rejected`に入っている写真（スタッフの仮のポーズ）をすべてごみ箱のアイコンで消してから、
2.〜4.で撮影します。8.では「モデルをアップロード」ではなく「**クラウドモデルを更新**」を押します。リンクは席ごとに決まっているので、提出しなくてかまいません。

## 考えてみよう

* 写真が少なすぎると、AIはどうなるでしょう？ 同じような写真ばかりだと？
* AIが覚えたのは「写真」そのものでしょうか？ それとも、写真の中の「体のかたち」でしょうか？

# 4. 仕上げて提出しよう（約6分）

## 4.1 絵を3つに分けて、背景を消す

1. Copilotの絵を「保存」→ PNGでダウンロードします。
2. ペイントで開き、**左の人物**を四角で選んで「トリミング」し、背景を消して、**`stand.png`**として保存します。
3. もう一度元の絵を開き、**まんなかの人物**を同じようにして、**`kime.png`**として保存します。
4. もう一度元の絵を開き、**右の人物**を同じようにして、**`rejected.png`**として保存します。

ファイル名は、この3つのとおりにします（半角小文字、`.png`を残す）。背景の消し方は、スタッフが前のスクリーンで見せます。

## 4.2 掲示板に出す

掲示板に、題名を「**NN 求婚者の名前**」（例：「07 入江の漁師」）にして投稿します。

* 画像3枚：`stand.png`・`kime.png`・`rejected.png`
* 本文：次の形で書きます。

```text
席番号：NN
作者の名前（紙芝居に出してよい名前）：
求婚者の名前：
決めポーズの説明：
ことわられたポーズの説明：
求婚の言葉：
手児奈のことわりの言葉：
ことわられたときのひとこと：
手児奈の心はゆれた？（ゆれた／ゆれなかった）：
モデルのリンク：https://teachablemachine.withgoogle.com/models/……
```

絵が先にできたら、絵とセリフを先に出し、モデルのリンクはあとから同じ投稿への返信で出してもかまいません。

## 4.3 （発展）自分の場面をためす

Scratchに慣れている人は、掲示板の「半完成品」（作業用SB3と台本`tekona.k4.yml`）を使って、自分の求婚者を自分のPCでためしてみましょう。

1. TurboWarp Plus Editorで作業用SB3を開き、自分の席番号のスプライト`SuitorNN`（例：`Suitor07`）を選びます。
2. 「コスチューム」タブで、仮の絵`stand`を削除してから`stand.png`をアップロードします。`kime`・`rejected`も同じようにします。
   コスチュームの名前が`stand`・`kime`・`rejected`になっていることを確かめます。
3. `tekona.k4.yml`をメモ帳で開き、「★参加者」と書かれた雛形をまねして、自分の場面を`quarrel:`の前に書き足します。
4. 緑の旗 → タイトルを閉じる → メニューの「開く」から`tekona.k4.yml`を選び、自分のカメラでポーズをためします。

くわしいやり方は掲示板の「発展課題」の投稿にあります。ためした台本は提出しなくてかまいません（スタッフが提出物から組み込みます）。

# 5. みんなで上演しよう（約6分）

スタッフが、提出された求婚者をみんなの紙芝居に組み込みます。
前のスクリーンで上演し、自分の求婚者の番が来たら、前のカメラの前に立って、求婚のポーズ（`kime`）とがっかりのポーズ（`rejected`）をキメてください。
組み込みずみの作品は掲示板にも出るので、自分のPCで見直すこともできます。

# 6. まとめ（約3分）

## 本当の言い伝え

今日の紙芝居では、手児奈は「わたしの心は、わたしのもの」と自分の生き方を選び、男たちは争いをやめて入江に橋をかけました。
これは、言い伝えをもとに新しくつくった**再話**です。

言い伝えでは、手児奈は自分のために人びとが争うことを悲しみ、夕日の入江に姿を消したといわれています。
里の人びとは手児奈を真間の井のそばにまつりました。いまも市川市真間には手児奈霊堂があり、
手児奈が水をくんだという真間の井も残っています。手児奈の話は、1300年ほど前の歌集『万葉集』にもうたわれています。

## 今日やったこと

* 地域の伝承を調べて、新しい登場人物をデザインしました。
* 生成AIに、決めたい絵の条件を言葉で伝えました。
* ポーズ認識AIに、自分のポーズを覚えさせました。AIは、たくさんのサンプルから「体のかたち」の特徴を学びます。
* みんなの作品を1つの紙芝居にまとめました。

## 写真と作品について

* Teachable Machineで撮った写真は、自分のPCの中だけにあります。体験会が終わったら、スタッフが削除します。
* 掲示板に出したモデルのリンクには、写真そのものは入っていません。写真から取り出した「体のかたち」の特徴だけが入っています。
* 掲示板は教室の中だけのものです。完成した紙芝居を教室の外で公開するときは、あらためて確認します。
