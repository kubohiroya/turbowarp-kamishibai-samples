# 手児奈 考証メモ（進行役用）

[`research-worksheet.md`](research-worksheet.md)の各問いに対する、進行役のための下調べです。参加者に答えを渡すためではなく、
話し合いで出た意見を受け止め、時代に合わない点に気づいてもらうための手がかりとして使います。

**確度の表記**：〔確〕複数の公的資料・注釈書で確かめられること／〔説〕資料や研究者によって異なる、または伝承の段階にあること／
〔要確認〕このメモの作成時に一次資料で確かめきれていないこと。教材として配る前に〔要確認〕を解消してください。

# 1. 基本設定

## 1.1 いつの時代の話か

* 『万葉集』の歌人たちは、すでに「古（いにしへ）にありけること」として歌っています。高橋虫麻呂の長歌（巻9・1807）は
  「鶏が鳴く　東の国に　古に　ありけることと　今までに　絶えず言ひける」と始まります。〔確〕
  つまり、奈良時代（8世紀前半）の人にとってすでに昔の話です。
* 市川市の資料などは「奈良時代より前」の人としています。舒明天皇のころの国造の娘とする後世の伝えもあります。〔説〕
* **紙芝居での設定案**：下総国府ができたころ（7世紀末〜8世紀前半）。国府の役人や都の貴族を登場させられ、
  万葉歌人が伝説を聞いた時代とも近いためです。厳密な年代は決められないことを、参加者にも伝えます。

## 1.2 どこの場所の話か

* 下総国葛飾郡（勝鹿）の真間。現在の千葉県市川市真間。〔確〕
* 当時は台地（国府台）の下まで海が入りこみ、市川砂州の内側に「真間の入江」がありました。〔確〕（市川市・このまちアーカイブス）
* 下総国府は国府台に置かれ、国庁は現在の千葉商科大学の周辺にあったと推定されています。〔説〕
  会場が千葉商科大学なら、「この場所の話」として導入に使えます。

## 1.3 主な登場人物

* 手児奈（真間の娘）、求婚する男たち、里の人びと。〔確〕
* 万葉歌の中で、求婚者の身分や名前は具体的には語られていません。〔確〕
  → 求婚者を考えることは、**伝承の空白を埋める創作**になります（4章）。

## 1.4 どんなストーリーか

* 真間の井で水をくむ手児奈は、粗末な身なりでも美しく、多くの男が言い寄った。手児奈は自分のことで人が争うのを悲しみ、
  入江に身を投げた（虫麻呂は「波の音の騒く湊の奥つ城」に眠ると歌う）。里人は井のそばに葬った。〔確〕
* 手児奈がいったん嫁いで戻ったなど、異なる筋の伝えもあります。〔説〕

## 1.5 歴史的要素・史実との関連

| 要素 | 内容 | 確度 |
| --- | --- | --- |
| 下総国府 | 国府台に置かれた下総国の役所。「国府台」の地名の由来 | 〔確〕 |
| 下総国分寺 | 天平13年（741）の国分寺建立の詔の後、近くに建立 | 〔確〕 |
| 官道と継橋 | 上総の国府へ向かう道が砂州を通り、入り江口の砂州をつなぐ橋が「真間の継橋」として歌われた | 〔説〕（市の説明看板） |
| 行基と弘法寺 | 天平9年（737）に行基が手児奈をとむらって求法寺を建て、のち弘法寺になったと伝える | 〔説〕（寺伝） |
| 葛飾郡の戸籍 | 正倉院文書に養老5年（721）の下総国葛飾郡大嶋郷の戸籍が残る。人びとの名前・続柄・年齢が分かる | 〔確〕 |

手児奈が実在したかどうかは確かめられません。史実（国府・国分寺・戸籍）と伝承（手児奈・行基の寺伝）を分けて扱います。

## 1.6 社会的評価・重要度

* 『万葉集』で山部赤人（巻3・431〜433）、高橋虫麻呂（巻9・1807〜1808）、東歌（巻14・3384〜3387）に歌われ、
  都の歌人にも東国の人びとにも知られた伝説でした。〔確〕
* 摂津の菟原処女（うないおとめ）など、複数の男に求婚された娘が死を選ぶ「妻争い伝説」の一つです。虫麻呂は両方を歌っています。〔確〕
* 現在は手児奈霊堂にまつられ、安産・子育ての神として参拝されています。真間の井（亀井院）、継橋とともに市川市の名所です。〔確〕

# 2. 歴史考証メモ

## 2.1 時代背景・自然・植生・地理

* 地形：北に下総台地（国府台）、その下に真間の入江、南に市川砂州。入江口の砂州を橋でつないで道が通った。
* 水：海に近く井戸水が塩けをおびる中で、真間の井は清水が出たと伝える（伝承）。
* 植生・生きもの〔要確認〕：入江の葦原、砂州の松（現在の黒松の景観は後世の可能性あり）、台地の雑木林。
  入江の玉藻（赤人の歌433「真間の入江にうち靡く玉藻刈りけむ」）〔確〕、水鳥（東歌3386の「にほ鳥」）〔確〕。
* **デザインへの反映**：背景は「台地・入江・砂州・葦」。入江に玉藻、水鳥を描くと歌とつながる。

## 2.2 文化習俗・技術・建築・道具

| 分野 | 内容 | 確度 |
| --- | --- | --- |
| 住まい | 東国の村では竪穴住居が長く使われた。国府・国分寺は礎石建ち・瓦葺きの建物 | 〔説〕〔要確認：下総の発掘例〕 |
| 赤人の歌の「伏屋」 | 低い小屋。「伏屋立て妻問ひしけむ」（431） | 〔確〕 |
| 井戸 | 木の枠を組んだ井戸。屋根・つるべの形は時代考証が必要 | 〔要確認〕 |
| 橋 | 砂州と砂州を板でつないだ「継橋」。平らな橋桁を杭で支える形が自然 | 〔説〕 |
| うつわ | 土師器（素焼き）・須恵器（灰色の硬いやきもの）。水がめは甕 | 〔確〕 |
| 漁具 | 丸木舟、網と土錘（あみのおもり）、釣針 | 〔要確認：市川の出土例〕 |
| 農具 | 鉄の刃先をつけた木のくわ・すき、鎌。田下駄 | 〔要確認〕 |
| 機織り | 麻を績（う）んで糸にし、機で布に織る。赤人の歌の「倭文幡（しつはた）の帯」は日本古来の織物 | 〔確〕 |

**時代に合わないものの例**：烏帽子・立烏帽子（平安時代以降に広まる）、ちょんまげ、着物の太い帯むすび、屋根つきの石組み井戸。

## 2.3 男女の衣装・装身具

| 人 | 素材・染料 | 形 | 身分の表し方 | 確度 |
| --- | --- | --- | --- | --- |
| 手児奈 | 麻。衿だけ青（藍などで染める） | 「麻衣に青衿着け　ひたさ麻を裳には織り着て」＝麻の上衣に青い衿、麻の裳（スカート状の衣） | 飾らない。「髪だにも掻きは梳らず　沓をだに穿かず」＝髪もとかさず、はだし | 〔確〕（巻9・1807） |
| 里の男 | 麻 | 上衣と袴。ひざ下をひもで結ぶ（足結）形が描かれることが多い | 冠・頭巾はかぶらない | 〔要確認〕 |
| 国府の役人（下級） | 絹または麻 | 袍（ほう）・袴に頭巾（黒い布のかぶりもの）、腰に帯、手に笏 | 位によって袍の色が決まる（位色）。六位は深緑、七位は浅緑、八位は深縹、初位は浅縹 | 位色は〔確〕、形の細部は〔要確認〕 |
| 都の貴族（五位以上） | 絹 | 同上 | 四位は深緋、五位は浅緋。三位以上は紫 | 〔確〕 |

* 染料〔要確認〕：藍（青）、紅花（紅）、茜（赤）、紫草（紫）、刈安（黄）。紫・緋は高い位の色で、庶民は使えない。
* 律令の衣服令では、自分の位の色より上の色を着ることは許されなかった。〔確〕
* 装身具：官人の帯の飾り（帯金具）、笏。庶民は飾りが少ない。〔要確認〕

## 2.4 政治・宗教・産業

* 政治：律令国家。都から国司（守・介・掾・目）が派遣され、国府で下総国を治めた。郡には地元の有力者が郡司として任じられた。〔確〕
* 負担：租・庸・調などの税、労役。東国からは防人（九州の守り）も出た。〔確〕
* 宗教：仏教を国家が保護し、国分寺を建てた。村では土地の神・水の神をまつった。〔確〕〔村の祭祀の具体例は要確認〕
* 産業：稲作（東歌3386「葛飾早稲」）、麻布づくり、漁撈。〔確〕〔麻布の調・漁撈の具体は要確認〕

## 2.5 暮らし・家族・婚姻

* 婚姻：男が女のもとへ通う「妻問ひ」が一般的で、同居はその後のことも多かった。赤人の歌の「妻問ひしけむ」もこの言葉。〔確〕
* 求婚：歌を詠みかけて思いを伝えることがあった。若い男女が集まって歌を交わす「歌垣（嬥歌）」もあった
  （虫麻呂は筑波山の嬥歌会を歌っている）。〔確〕
* 家族：戸籍は戸主を筆頭に、家族・親族を一人一行で記録した。女性の名は「〜売（め）」が多い。〔確〕（大嶋郷戸籍）

**デザインへの反映**：求婚の演技に「歌を詠みかける」「贈り物（布・魚・稲）を差し出す」を取り入れると時代に合う。

# 3. 手児奈という人物の姿

## 3.1 言い伝えられている姿

* 粗末な麻の衣に青い衿、麻の裳、髪はとかさず、はだし。それでも、錦や綾に包まれて大事に育てられた娘より美しい。〔確〕（巻9・1807）
* 満月のような顔で、花のように笑って立つ。〔確〕（同）
* 真間の井で水をくむ。〔確〕（巻9・1808「真間の井見れば立ち平し水汲ましけむ手児奈し思ほゆ」）
* 入江で玉藻を刈る。〔確〕（巻3・433）
* 身分について「婢（めしつかい）」とする説、国造の娘とする伝えなどがある。〔説〕
* 「てこ」は東国の言葉で少女・娘を指すとする説がある。〔説〕

## 3.2 取捨選択とアレンジの観点（話し合いの例）

| 要素 | 本作（仮素材）での扱い | 理由・論点 |
| --- | --- | --- |
| 麻の衣・青い衿・麻の裳 | 残す | 歌に書かれた、もっとも確かな姿 |
| 髪をとかさない・はだし | 一部残す（はだし、髪は長くまっすぐ） | 「飾らない美しさ」を表す。乱れ髪を描くかは話し合いどころ |
| 満月の顔・花の笑み | 残す | 表情の手がかり |
| 水がめ・真間の井 | 残す | 舞台と行動を結ぶ |
| 髪飾り | 外す | 歌の「飾らない」姿と合わない |
| 入水の結末 | 変える（自分の生き方を選ぶ）。最後に本来の言い伝えを紹介 | 対象年齢への配慮。伝承を消さずに伝える |
| 身分 | ふれない | 説が分かれ、物語の中心ではない |

論点：伝承を「正しく伝える」ことと「いまの観客に向けて語りなおす」ことは、どちらも大切です。変えた部分は、変えたと明示します。

# 4. 求婚者として想定され得る人物

1〜3を踏まえた候補です。**里の若者・国府の役人・都の貴族**の3人は仮素材として作成済みで、残りは当日の「4人目」の参考案です。
決めポーズはポーズ認識のため、既存の`stand`／`heart`／`offer`／`wide`と上半身で区別できるものにします。

| # | 身分・職業 | 人物特性・表情 | 服装・髪型・装身具 | 演技・セリフ（求婚） | ポーズ案 |
| --- | --- | --- | --- | --- | --- |
| 1 | 里の若者（農民） | 元気で正直。満面の笑み | 麻の上衣と袴、髪は頭の上でまとめる。はだし | 「毎日、水がめを運ぶのを手伝います！」 | `heart`：両うでで頭上にハート（作成済み） |
| 2 | 国府の役人（下級の官人） | まじめで几帳面。少し緊張 | 深緑の袍、黒い頭巾、笏 | 「あなたを一生守ってみせましょう」 | `offer`：片手を胸、片手をさしだす（作成済み） |
| 3 | 都から来た貴族（五位） | 自信家で派手好き | 浅緋の袍、黒い頭巾、笏 | 「都の屋敷も、絹の着物も、ぜんぶあなたのもの」 | `wide`：両うでを横に広げる（作成済み） |
| 4 | 入江の漁師 | 日焼けして豪快 | 麻の短い上衣、腰にびく | 「この入江でいちばんの魚を、毎朝とどけよう」 | 網を投げる：両うでを斜め上へ振り上げる |
| 5 | 歌の上手な若者（歌垣の名手） | ロマンチスト。目を閉じてうっとり | 麻の衣、草花を髪にさす | 五・七・五・七・七の歌を詠みかける | 片手を耳に、片手を高く上げて歌う |
| 6 | 郡司の息子（地元の有力者） | 少しいばっている | 色のついた衣、帯の飾り、馬のむち | 「わが家の田は、この葛飾でいちばん広いぞ」 | 両手を腰に当てて胸を張る |
| 7 | 防人に出る若者 | 決意と不安 | 麻の衣に弓や矢筒 | 「遠い九州から帰ったら、妻になってくれないか」 | 弓を引く：片うでを前に伸ばし、片ひじを後ろへ引く |
| 8 | 機織りの名人の若者 | 器用で物静か | 自分で織った布をたすきにかける | 「あなたのために、いちばん美しい布を織りました」 | 布を広げる：両手を胸の前で左右へ開く |

* 7は史実（防人）にもとづく重い設定です。扱う場合は、防人が家族と離れるつらい務めだったことにふれます。
* 手児奈の断りの言葉は、どの人物にも「やさしく、はっきり」を基本にします。相手の身分や財産ではなく、
  手児奈自身の気持ちで断る形にすると、結末の「わたしの心は、わたしのもの」とつながります。

## 立ち絵・ポーズ・表情のバリエーション

紙芝居で使うのは、各求婚者につき**立ち絵**と**決めポーズ**の2枚です（台本の`stand`と`poseSkin`）。
発展として次の差分を加えると、台本の「とほほ……」の場面などで使えます（追加にはコスチュームと台本の列の追加が必要）。

* 断られたとき（肩を落とす、頭をかく）
* 心がゆれた手児奈を見て期待する顔
* 争いの場面の怒った顔

# 5. 仮素材への反映

この考証にもとづき、`stories/tekona/assets/`の仮素材を次のように直しました。

| 素材 | 変更 |
| --- | --- |
| 手児奈 | 衣を生成りの麻の色に、衿を青に。髪飾りを外し、はだしにした |
| 里の若者 | 鉢巻をやめ、頭の上で髪をまとめた形にした |
| 国府の役人 | 烏帽子を黒い頭巾に替え、深緑の袍（六位）に笏を持たせた |
| 都の貴族 | 立烏帽子を黒い頭巾に、紫（三位以上）の袍を浅緋（五位）に替え、笏を持たせた |
| 真間の井 | 屋根つきの石組みをやめ、木の枠の井戸にした。背景に伏屋（竪穴住居）を加えた |
| 継橋 | 太鼓橋をやめ、砂州と砂州を平らな板橋でつないだ形にした |
