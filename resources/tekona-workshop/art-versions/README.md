# 手児奈の仮素材：絵柄の版の記録

`stories/tekona/assets/`の仮素材（立ち絵・ポーズ絵・背景のSVG）を描き直してきた版を、参考用にそのまま保存しています。
作品のSB3が使うのは`stories/tekona/assets/`だけで、このフォルダはSB3の生成には使いません。

| 版 | フォルダ | 元のコミット | 絵柄 |
| --- | --- | --- | --- |
| 1 | [`v1-simple/`](v1-simple/) | `0c6ddfd`（描き直し前） | 輪郭線のない、シンプルな平面イラスト。人物は正面向き |
| 2 | [`v2-detailed/`](v2-detailed/) | `e159f7b` | 平面イラストのまま、[考証メモ](../research-notes.md)の衣装・背景を描き込んだ版。求婚者は手児奈のほうを向く |
| 3 | [`v3-anime/`](v3-anime/) | `d525136`（いったん採用し、版2へ戻した） | アニメ調。細い輪郭線とアニメ塗り（光は左上、影1段）、6頭身前後。背景はグラデーションと光の反射を入れたアニメ背景風 |
| 4 | [`v4-detailed-acting/`](v4-detailed-acting/) | このフォルダで追加（現在の`stories/tekona/assets/`） | 版2の絵柄のまま、人体と芝居を見直した版。背景は版2と同じ |

各フォルダの中身：

| ファイル | 内容 |
| --- | --- |
| `assets/*.svg` | その版の素材一式。ファイル名・大きさ（人物240×380、背景480×360）・回転の中心は全版で共通なので、`stories/tekona/assets/`へ戻せばその版の絵でSB3を作れる |
| `preview.png` | 素材の一覧（人物の背景の水色は確認用） |
| `style-reference.png` | その版の`copilot/style-reference.png`（Copilotに添付する絵柄の見本） |
| `generator/`（版2〜版4） | SVGを生成したスクリプト。`node generator/chars.cjs 出力先フォルダ`、`node generator/backdrops.cjs 出力先フォルダ`で、`assets/`と同じSVGを出力する |

補足：

* 版1は手描きのSVGで、生成スクリプトはありません。
* 版2の生成スクリプトは手児奈・用意済み3人・背景を出力します。参加者の枠の「？」の人物（`newcomer-*`）と`text-placeholder.svg`は版1と同じものです。
* 版3・版4の生成スクリプトは`newcomer-*`も出力します。`text-placeholder.svg`は全版で同じです。
* 参加者向け資料のCopilotへの依頼文は、版4（版2と同じ平面イラスト）に合わせて絵柄を「太い輪郭線のない、シンプルな平面イラスト」と指定しています。
  版3の絵を使うときは、[`tekona-workshop.md`](../tekona-workshop.md)の依頼文を「細い輪郭線とアニメ塗りの、アニメ調のイラスト。6頭身くらい」に変えてください。

## 版4で版2から直したこと

* **骨格から描く**：肩・肘・手首、股関節・膝・足首の位置を決め、上腕と前腕、ももとすねの長さを固定して計算します。
  関節は1か所でしか曲がらないので、版2の一部にあった「肘が2つあるように見える腕」はなくなりました。
* **頭身と首**：求婚者は7頭身弱、手児奈は7頭身前後にし、首を短く太くしました（版2は4〜5頭身で首が長かった）。
* **男性らしさ**：求婚者は肩幅を広げ、首を太くし、あごの張った輪郭・ほお骨・鼻筋・太い眉・切れ長の目にしました。
  里の若者は日焼けした肌と無精ひげ、都の貴族は口ひげ・あごひげとほうれい線で年かさを出しています。
* **下半身の芝居**：
  * `stand`：片足を少し前に出し、両足に体重をのせる。官人は笏を両手で持つ（都の貴族は片手を腰に当てて胸を張る）。
  * `kime`：手児奈のほう（画面の左）へ一歩ふみ出し、前のひざを曲げ、後ろ足のかかとを上げ、上体を前へ傾ける。
  * `rejected`：ひざから力がぬけて腰が落ち、後ろへよろめく。肩を落とし、両手をだらりと下げ、うつむく
    （参加者の`rejected`のポーズ「肩を落として両手を下に垂らし、うつむく」と同じ上半身）。
  * 手児奈：`stand`は片足に体重をのせて水がめをかかえる、`refuse`は上体を少し引いて手のひらを相手へ向ける、`resolve`は足をそろえて両手を胸に当てる。
* **顔の配置（3/4の向き）**：顔が向いている側（鼻のある側）の目が奥の目です。奥の目と眉・ほおの赤みを手前より小さく、横に縮めて描きます
  （手児奈は画面の右、求婚者は画面の左が奥）。手児奈は口を両目のあいだの下へ寄せ、輪郭から出ていた鼻の三角をなくしました。
  求婚者の鼻は輪郭から出さず、両目のあいだ（奥の目寄り）に鼻筋の影と小鼻で描き、口・ひげもその下にそろえています。
* 衣装・色・背景は版2のまま（考証メモ5章のとおり）です。
