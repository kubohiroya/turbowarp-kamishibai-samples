作品のSB3が使うのは`stories/tekona/assets/`だけで、このフォルダはSB3の生成には使いません。

各フォルダの中身：

| ファイル | 内容 |
| --- | --- |
| `assets/*.svg` | その版の素材一式。ファイル名・大きさ（人物240×380、背景480×360）・回転の中心は全版で共通なので、`stories/tekona/assets/`へ戻せばその版の絵でSB3を作れる |
| `preview.png` | 素材の一覧（人物の背景の水色は確認用） |

| `generator/`（版2〜版4） | SVGを生成したスクリプト。`node generator/chars.cjs 出力先フォルダ`、`node generator/backdrops.cjs 出力先フォルダ`（版4は`stork.cjs`・`kokubunji.cjs`・`village.cjs`・`sea.cjs`・`extra.cjs`・`tenkei.cjs`も同じように）で、`assets/`と同じSVGを出力する |

補足：

* 版1は手描きのSVGで、生成スクリプトはありません。
* 版2の生成スクリプトは手児奈・用意済み3人・背景を出力します。参加者の枠の「？」の人物（`newcomer-*`）と`text-placeholder.svg`は版1と同じものです。
* 版3・版4の生成スクリプトは`newcomer-*`も出力します。`text-placeholder.svg`は全版で同じです。
* 参加者向け資料のCopilotへの依頼文は、版4（版2と同じ平面イラスト）に合わせて絵柄を「太い輪郭線のない、シンプルな平面イラスト」と指定しています。
  版3の絵を使うときは、[`tekona-workshop.md`](../tekona-workshop.md)の依頼文を「細い輪郭線とアニメ塗りの、アニメ調のイラスト。6頭身くらい」に変えてください。

## 版4で版2から直したこと

* **骨格から描く**：肩・肘・手首、股関節・膝・足首の位置を決め、上腕と前腕、ももとすねの長さを固定して計算します。
  関節は1か所でしか曲がらないので、版2の一部にあった「肘が2つあるように見える腕」はなくなりました。
* **頭身と首**：求婚者は7頭身弱、手児奈は7頭身前後にし、首を短く太くしました（版2は4〜5頭身で首が長かった）。
* **男性らしさ**：求婚者は肩幅を広げ、首を太くし、あごの張った輪郭・ほお骨・鼻筋・太い眉・切れ長の目にしました。
  里の若者は日焼けした肌と無精ひげ、都の貴族は口ひげ・あごひげとほうれい線で年かさを出しています。
* **下半身の芝居**：
  * `stand`：片足を少し前に出し、両足に体重をのせる。官人は笏を両手で持つ（都の貴族は片手を腰に当てて胸を張る）。
  * `kime`：手児奈のほう（画面の左）へ一歩ふみ出し、前のひざを曲げ、後ろ足のかかとを上げ、上体を前へ傾ける。
  * `rejected`：**人物ごとに違う崩れ方**にしました。基本形（ひざから力がぬけて腰が落ち、後ろへよろめき、肩を落として両手をだらりと下げ、うつむく）は、
    参加者の枠の「？」（`newcomer-rejected`）がそのまま使います。参加者の`rejected`のポーズ「肩を落として両手を下に垂らし、うつむく」の手本にあたるからです。
    8人の求婚者は、同じ基本形から次のように変えています。断られ方が全員同じだと、くり返しの場面が一本調子になるためです。
    どれも**カメラの前で人がとるポーズでもある**ので、8人とも立った姿勢のまま、腕と頭の形だけで変えています。
    ポーズ認識モデルは上半身の関節の位置で判別するため、(1)その人物の`stand`・`kime`と**腕の形で**区別でき、(2)数秒止まれて、(3)周囲にぶつからない形である必要があります。
    表情・顔の向き・小道具は判別に使えないので、3つのポーズは腕と頭の位置だけで分かれている必要があります。
    ひざをつく・腰砕け・尻もちは、絵としては成立しても上半身だけの画角では区別できず、教室で数秒止まることもできないので採っていません。
    * 里の若者：ひざは折れず、前かがみのまま立ちつくす。両腕はだらりと下げる。目を見開き、口を小さくあけて呆然とする。
    * 国府の役人：笏を取り落として足もとに落とし、背すじをのばしたまま深く頭を下げる。
    * 都の貴族：上体を引き、片手で口元を覆う。笏はもう片方の手にだらりと下げる。目を見開く。
    * 入江の漁師：網を足もとに取り落とし、立ったまま両手で頭を抱えてうなだれる。
    * 歌の上手な若者：片手の甲を額に当て、のけぞって天をあおぐ。もう片方の手はだらりと下げる。
    * 郡司の息子：むちを取り落とし、腰から手を離して腕を組み、あごを上げて強がる
      （`kime`の「両手を腰に当てて胸を張る」と腕の形が重なってモデルが区別できなくなるので、手を腰から胸の前へ移した）。
    * 防人に出る若者：ひざを折らず、肩だけ落としてまっすぐ立つ。弓の先を地につけ、その上に両手を重ねて手児奈を見返す（汗は描かない）。
    * 機織りの名人の若者：織った布を両手で胸に抱きしめ、背を丸めて静かにうつむく。
  * 手児奈：`stand`は片足に体重をのせて水がめをかかえる、`refuse`は上体を少し引いて手のひらを相手へ向ける、`resolve`は足をそろえて両手を胸に当てる。
* **顔の配置（3/4の向き）**：顔が向いている側（鼻のある側）の目が奥の目です。奥の目と眉・ほおの赤みを手前より小さく、横に縮めて描きます
  （手児奈は画面の右、求婚者は画面の左が奥）。手児奈は口を両目のあいだの下へ寄せ、輪郭から出ていた鼻の三角をなくしました。
  求婚者の鼻は輪郭から出さず、両目のあいだ（奥の目寄り）に鼻筋の影と小鼻で描き、口・ひげもその下にそろえています。
* **表情**：`stand`・`eager`・`serious`・`proud`・`pained`・`focus`に、言葉を失って見開いた目と小さくあいた口の`stunned`（呆然）を加えました。
* **求婚者の顔立ちの描き分け**：髪型やひげだけでなく、輪郭・目・眉・鼻・口を人物ごとに変えています。
  * 里の若者：丸みのある広い顔、丸い目、太くまっすぐな眉、だんご鼻、大きな口。
  * 国府の役人：面長で細いあご、切れ長の細い目、細く上がった眉、細く長い鼻、小さく薄い口。
  * 都の貴族：ふくよかなほおと二重あご、重いまぶたと涙袋、弧を描く眉、鼻筋の通った大きな鼻、厚い唇。
  * 入江の漁師：角張った広い顔とまっすぐなあごの線、大きく見開いた丸い目、太く短い眉、横に広い鼻、大きな口。
  * 歌の上手な若者：細くやさしい顔、大きめの目、細く弧を描く眉、小さく通った鼻、やわらかい厚めの口。
  * 郡司の息子：下ぶくれでほおが張った顔、小さく細い目、太い眉、短く上を向いた鼻、小さくとがった口。
  * 防人に出る若者：縦長でひきしまった顔、大きめの切れ長の目、太くまっすぐな眉、細くまっすぐな鼻、引き結んだ口。
  * 機織りの名人の若者：卵形のおもながな顔、細い目、薄い眉、細く小さい鼻、小さく静かな口。
* 衣装・色は、用意済み3人は版2のまま（考証メモ5章のとおり）です。
* **求婚者を8人にした**（版4の中での追加。絵柄・画像サイズ・回転の中心・顔の向きは3人とまったく同じ）：考証メモ4章の表の#4〜#8を、
  同じ生成スクリプトの仮素材にしました（`ryoshi`／`utabito`／`gunji`／`sakimori`／`hataori`の3枚ずつ）。
  庶民の衣（`satoFigure`）は、色・顔立ち・髪型・上衣の丈・帯の飾りを人物ごとに差し替えられるようにしてあります。
  * 入江の漁師（`ryoshi-*`）：日焼けした肌と無精ひげ、短く刈って毛先の立った髪、袖をまくった前腕。薄い藍の麻の**短い**上衣と青灰の袴、腰に草で編んだびく（魚かご）。
    `kime`は両うでを斜め上へ振り上げ、頭の後ろで投網を大きく開く（網は体より後ろに描く）。`rejected`では網が足もとに落ちる。
  * 歌の上手な若者（`utabito-*`）：さらした白い麻の衣、髻に草花をさす。`kime`は目を閉じて口をあけ、遠いほうの手をひじを外へ張って耳に当て、
