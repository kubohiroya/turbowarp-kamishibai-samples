# 手児奈の仮素材：絵柄の版の記録

`stories/tekona/assets/`の仮素材（立ち絵・ポーズ絵・背景のSVG）を描き直してきた版を、参考用にそのまま保存しています。
作品のSB3が使うのは`stories/tekona/assets/`だけで、このフォルダはSB3の生成には使いません。

| 版 | フォルダ | 元のコミット | 絵柄 |
| --- | --- | --- | --- |
| 1 | [`v1-simple/`](v1-simple/) | `0c6ddfd`（描き直し前） | 輪郭線のない、シンプルな平面イラスト。人物は正面向き |
| 2 | [`v2-detailed/`](v2-detailed/) | `e159f7b` | 平面イラストのまま、[考証メモ](../research-notes.md)の衣装・背景を描き込んだ版。求婚者は手児奈のほうを向く |
| 3 | [`v3-anime/`](v3-anime/) | `d525136`（いったん採用し、版2へ戻した） | アニメ調。細い輪郭線とアニメ塗り（光は左上、影1段）、6頭身前後。背景はグラデーションと光の反射を入れたアニメ背景風 |
| 4 | [`v4-detailed-acting/`](v4-detailed-acting/) | このフォルダで追加（現在の`stories/tekona/assets/`） | 版2の絵柄のまま、人体と芝居を見直した版。背景は版2に松・小道具・グラデーションを加えた。コウノトリの3枚絵つき |

各フォルダの中身：

| ファイル | 内容 |
| --- | --- |
| `assets/*.svg` | その版の素材一式。ファイル名・大きさ（人物240×380、背景480×360）・回転の中心は全版で共通なので、`stories/tekona/assets/`へ戻せばその版の絵でSB3を作れる |
| `preview.png` | 素材の一覧（人物の背景の水色は確認用） |
| `style-reference.png` | その版の`copilot/style-reference.png`（Copilotに添付する絵柄の見本） |
| `generator/`（版2〜版4） | SVGを生成したスクリプト。`node generator/chars.cjs 出力先フォルダ`、`node generator/backdrops.cjs 出力先フォルダ`（版4は`stork.cjs`・`kokubunji.cjs`・`village.cjs`・`sea.cjs`も同じように）で、`assets/`と同じSVGを出力する |

補足：

* 版1は手描きのSVGで、生成スクリプトはありません。
* 版2の生成スクリプトは手児奈・用意済み3人・背景を出力します。参加者の枠の「？」の人物（`newcomer-*`）と`text-placeholder.svg`は版1と同じものです。
* 版3・版4の生成スクリプトは`newcomer-*`も出力します。`text-placeholder.svg`は全版で同じです。
* 参加者向け資料のCopilotへの依頼文は、版4（版2と同じ平面イラスト）に合わせて絵柄を「太い輪郭線のない、シンプルな平面イラスト」と指定しています。
  版3の絵を使うときは、[`tekona-workshop.md`](../tekona-workshop.md)の依頼文を「細い輪郭線とアニメ塗りの、アニメ調のイラスト。6頭身くらい」に変えてください。

## 版4で版2から直したこと

* **骨格から描く**：肩・肘・手首、股関節・膝・足首の位置を決め、上腕と前腕、ももとすねの長さを固定して計算します。
  関節は1か所でしか曲がらないので、版2の一部にあった「肘が2つあるように見える腕」はなくなりました。
* **頭身と首**：求婚者は7頭身弱、手児奈は7頭身前後にし、首を短く太くしました（版2は4〜5頭身で首が長かった）。
* **男性らしさ**：求婚者は肩幅を広げ、首を太くし、あごの張った輪郭・ほお骨・鼻筋・太い眉・切れ長の目にしました。
  里の若者は日焼けした肌と無精ひげ、都の貴族は口ひげ・あごひげとほうれい線で年かさを出しています。
* **下半身の芝居**：
  * `stand`：片足を少し前に出し、両足に体重をのせる。官人は笏を両手で持つ（都の貴族は片手を腰に当てて胸を張る）。
  * `kime`：手児奈のほう（画面の左）へ一歩ふみ出し、前のひざを曲げ、後ろ足のかかとを上げ、上体を前へ傾ける。
  * `rejected`：ひざから力がぬけて腰が落ち、後ろへよろめく。肩を落とし、両手をだらりと下げ、うつむく
    （参加者の`rejected`のポーズ「肩を落として両手を下に垂らし、うつむく」と同じ上半身）。
  * 手児奈：`stand`は片足に体重をのせて水がめをかかえる、`refuse`は上体を少し引いて手のひらを相手へ向ける、`resolve`は足をそろえて両手を胸に当てる。
* **顔の配置（3/4の向き）**：顔が向いている側（鼻のある側）の目が奥の目です。奥の目と眉・ほおの赤みを手前より小さく、横に縮めて描きます
  （手児奈は画面の右、求婚者は画面の左が奥）。手児奈は口を両目のあいだの下へ寄せ、輪郭から出ていた鼻の三角をなくしました。
  求婚者の鼻は輪郭から出さず、両目のあいだ（奥の目寄り）に鼻筋の影と小鼻で描き、口・ひげもその下にそろえています。
* **求婚者の顔立ちの描き分け**：髪型やひげだけでなく、輪郭・目・眉・鼻・口を人物ごとに変えています。
  * 里の若者：丸みのある広い顔、丸い目、太くまっすぐな眉、だんご鼻、大きな口。
  * 国府の役人：面長で細いあご、切れ長の細い目、細く上がった眉、細く長い鼻、小さく薄い口。
  * 都の貴族：ふくよかなほおと二重あご、重いまぶたと涙袋、弧を描く眉、鼻筋の通った大きな鼻、厚い唇。
* 衣装・色は版2のまま（考証メモ5章のとおり）です。
* **昼の背景（真間の井・継橋）の構図**：人物と表情が目立つよう、次のように描き直しました。
  * 水平線（遠くの海・砂州・台地のすそ）を、夕日の入江と同じく人物の顔より下（y≈200）に下げ、台地と木も低くした。
  * 全体を明るく淡い色へ寄せ、明暗の差を小さくした。
  * 井戸・伏屋・かご・水がめは画面の左（手児奈の後ろ）、丸木舟・干した網は右（求婚者の後ろ）に寄せ、画面の中央をあけた。
  * 入江の水鳥（にほ鳥）をなくした。
  * 入江の玉藻を、本数・間隔・高さ・傾き・揺れ方をばらつかせて不規則に生やし、ところどころに細長い葉をつけた。
  * 継橋を、水面すれすれの低い板橋にし、杭を短くした。
  * 継橋は人物の足もとが水になっていたので、画面の手前にゆるやかな起伏のある低い砂地（浜）を置き、人物がその上に立つようにした。
* **背景**：版2の構図のまま、次を加えました。
  * 空・海・砂地を単色から淡いグラデーションにし、波打ちぎわに濡れた砂の帯を入れた。
  * 砂州の松を、1本ずつ高さ・幹の曲がり・海側への傾き・葉の段の数が違う松にした（版2は同じ形の木を並べていた）。
  * 小道具：岸に引き上げた丸木舟と櫂、竿に干した網と土錘、井戸のそばの草で編んだかご（魚・菜）、
    継橋のたもとにつないだ丸木舟と橋の上のかご、夕日と月夜の入江の丸木舟（シルエット）。人物と重ならない位置に置いています。
* **国分寺の建設の背景**（`kokubunji.svg`、480×360）：考証メモ1.5（天平13年の国分寺建立の詔のあと、国府台の近くに下総国分寺が建てられた）にもとづく場面。
  * 遠景：上が平らな小高い丘の上で、石の基壇に丹塗りの柱を立てた大きな金堂を建てている。金堂のまわりは広い平地で、丘の左端（画面の左端近く）が切り立った崖になり、崖の向こう（左手奥）に大きな川の下流（国府台の西を流れる、いまの江戸川にあたる川）が見え、向こう岸には低い丘と木が連なる。屋根は左半分を瓦でふき終え、右半分は垂木がむき出し。
    丸太を縄で縛った足場の上で、瓦を運ぶ・渡す・ふく労務者、綱で材を引き上げる労務者、丸太をかつぐ労務者を小さく描いた。遠景は空気の色へ寄せて淡くしている。
  * 手前（画面の中央よりやや右）：むしろに片ひざをついて座り（手前の右ひざを立て、すねは足先へ下ろす）、上体を乗り出して顔を仏像に近づけ、
    目をわずかに細めて口を静かに結んだ真剣な表情（眉は寄せすぎず、眉間のしわは描かない）で、奥の右腕で木槌を頭の後ろへ振り上げ、手前の左腕でノミの刃先を仏像の胸に当てる仏師。
    材木と道具は手前の左に置いた。仏像は濃い茶色の木の立像で、上半身は肉髻・螺髪・長い耳たぶ・伏し目・白毫・衣のひだまで彫り出し、下半身は荒彫りの角材のままにして、まわりに木くずを散らした。
  * 仏師は求婚者と同じ骨格の描き方（`generator/chars.cjs`の部品を`generator/kokubunji.cjs`から使う）で描いている。
    台本`stories/tekona/tekona.k4.yml`の後日談`kokubunji`（継橋の場面のあと、`afterword`の前）で、背景`Kokubunji`として使っています。
* **里の暮らしの3場面**（480×360。考証メモ2.2〜2.5にもとづく。台本と`project-assets-dsl4.yml`にはまだ登録していません）
  * 井戸端（`ido-bata.svg`）：水をくむ動作がわかるよう、縄をつけた木桶を井戸から引き上げる女（腰を落として上体を後ろへ引き、手をかえて縄をたぐる。桶から水がしたたる）と、
    木桶をかたむけて地面の水がめへ水を移す女（桶の重さで腰を落とし、ひじを張る）を中心に置いた。
    水がめを運ぶ女は重さが伝わる姿勢にした：頭にのせる女は、頭頂の輪の上、頭・体・足の重心が一直線になる真上に大きな水がめをのせ、片手で支えて伏屋へ帰っていく後ろ姿で、肩ごしにこちらを振り向き、ほお・片目・口もとが少し見える。
    腰に当てる女は、大きな水がめを体に沿って抱き寄せ、重さで上体を反らして肩を下げる。
    人物の向き（右向き・左向き・後ろ姿）と前後の重なりを変え、井戸のふちに手をかけてのぞきこむ子、女のすそにつかまって見上げる子、丸太に腰かけて身ぶりをまじえて笑う白髪の老女を置いた。
  * 網漁（`ryo.svg`）：穏やかに凪いだ近海。舟の上の男たちは、腰を低く落とし足を開いてふんばる（重心が高いと舟から落ちる）。手前の大きめの丸木舟（画面の左寄り）では、舳先の男が腕を前へのばして投網を打ち、網は空中で丸く平らに広がって、
    ふちの土錘とともに水面へ落ちていく（真ん中の手綱は男の手へ）。艫の男は片ひざをついて櫂をこぐ。
    奥の舟では、右の男が網をたぐり上げ、浮きのついた網の中で魚が跳ねる。左の男は体を左へ向け、身をかがめて舟の中を見下ろす。遠くに松の陸と小さな舟、かもめ。
  * 遠浅の浜（`hama.svg`）：干潟で身をかがめて貝を拾う女、しゃがんで海藻をつむ女、かごを腰にかかえて子どもに声をかける女、
    拾った貝を高くかかげる子、しゃがんで砂をほる子。草で編んだかごに貝や海藻を集める。ぬれた砂に空を映す水たまり、貝と海藻。
  * 子どもの耳の横で束ねた髪は、頭の向こう側（顔の側）の房を描かない（顔の前にかからないように）。
  * 女は麻の上衣（右前）と裳、ひもの帯、はだし。髪は後ろで束ねるかまげにまとめ、老女は白髪。子どもはひざ丈の上衣ひとつ。男は里の若者と同じ麻の上衣と袴。
  * 人物は`generator/chars.cjs`（顔・骨格・手足、男の姿）と`generator/village.cjs`（女・子どもの姿）の部品で描いている。
    女の表情に、笑う顔（laugh）・話す顔（talk）と、年寄りの顔（しわ）を加えた。手児奈と求婚者の絵は変わらない。
* **コウノトリの9枚絵**（`stork-1`〜`stork-9`、320×240）：水辺から飛び立つアニメーション。大型の鳥なので真上には跳ばず、次の順に動きます。
  1. 飛ぶ前の姿勢：あごを少し引き、翼を体に引き寄せてたたみ、重心を高くして立つ。手前の足を軽く上げ、奥の足に力を込めてまっすぐ立ち、遠く前方を見る。
  2. 身をかがめ、翼を半分ひらいて構える（翼は肩から上方向へ1.4倍に伸ばして大きく見せる）。
  3. 斜め前へ身を乗り出し、脚で水を後ろへけり出す（しぶき）。胴体は前に傾き、重心は2枚目よりいったん下がる。翼は打ちおろしの前で高く上げている。
  4. 翼を打ちおろして風をとらえ、前へ進みながら上がる。首を水平にのばして頭を重心（胴体の中心）と同じ高さに置き、脚は後ろへのばす。翼は首にかからないよう肩から下へ打ちおろす。
  5. 羽ばたきのあと、風をとらえた翼を大きく広げ（初列風切は指のように分かれる）、少し傾いて画面の奥へ向きを変えはじめる。
  6. さらに傾いて画面の奥へゆっくり旋回し、小さく遠ざかる。
  7〜9. 旋回を続けながら画面の奥へゆっくり遠ざかる。位置は6枚目から左上へ進み、右へ回り込む弧を描く。だんだん小さくなり、最後は影絵のような一色のシルエットになる。
  5〜9枚目は首を水平かやや下げて頭を低めに置き、遠ざかるにつれて色を空の青灰色へ寄せて暗く、明暗の差を小さくしている（5枚目22%、6枚目36%、7枚目52%、8枚目70%、9枚目90%）。

  9枚とも水面の高さ（y=170）をそろえてあります。鳥は2枚目から1枚ごとに前（画面の左）へ進み、飛び立った場所の波紋は、鳥から見て後ろ（右）へ遠ざかります。
  波紋の中心は、1・2枚目は足もと、3枚目は後ろへけり出した足先よりさらに右、4枚目は画像の右へ見切れる位置で、5枚目以降には映りません。
  回転の中心は9枚共通で、水面の上の点（画像の左上から198, 210）です。

  白い体・黒い風切羽・黒いくちばし、目のまわりと脚は赤。目は頭の中ほどより少し上。尾羽は後ろへ行くほど細くなる三角で、白い毛の筆に墨を不均一につけたように先へ向かって黒い筋が濃くなり、先を下へ向ける。
  肩から上腕を白い斜めの楕円で描いて翼を胴体の前寄りから生やし、脚の付け根（すねの上）は羽毛の白い斜めの楕円でおおう。足は前の3本の指と付け根の水かき、後ろの短い指。
  5〜9枚目は、翼を広げた姿を立体で組み、傾き・向き・見上げる角度を変えて平面に写して描いています（`generator/stork.cjs`の`soar`）。
  台本`stories/tekona/tekona.k4.yml`のアバンタイトル`avant`で、背景を省いた無地の背景`avant-blank.svg`（`AvantBlank`）の上に置き、スプライト`Stork`（`project-assets-dsl4.yml`）のコスチュームとして順に切り替えています。
