# 調べて、えらんで、デザインする ― 手児奈ワークシート

紙芝居「手児奈」の登場人物をつくる前に、物語の時代と土地を調べます。
調べたことをそのまま使う必要はありません。**何を残し、何を変えるかを自分で決める**ことが、再話（語りなおし）です。

各項目には「わかったこと」と「どこで調べたか（出典）」の両方を書きましょう。
出典がはっきりしないことは「？」をつけておきます。

## 調べるときに使えるもの

* 『万葉集』の手児奈の歌（巻3の431〜433番、巻9の1807〜1808番、巻14の3384〜3387番）
  * 奈良県立万葉文化館「[万葉百科](https://manyo-hyakka.pref.nara.jp/)」で歌番号から読めます。
* 市川市「[真間の手児奈](https://www.city.ichikawa.lg.jp/page/4573.html)」、市川市の文化財・考古の資料
* 歴史の教科書・資料集（奈良時代、律令、国府、国分寺）
* 博物館：市川市立市川考古博物館・市川歴史博物館、国立歴史民俗博物館 など
* 現地：手児奈霊堂、亀井院（真間の井）、継橋、弘法寺、下総国分寺跡、国府台

# 1. 基本設定

| 問い | わかったこと | 出典 |
| --- | --- | --- |
| 1. これはいつの時代の話？ ヒント：万葉集の歌人たちは、この話を「いつ」のこととして歌っている？ | | |
| 2. これはどこの場所の話？ ヒント：「葛飾（勝鹿）の真間」は今のどこ？ 当時の海岸線は？ | | |
| 3. 主な登場人物は誰？ | | |
| 4. どんなストーリー？（3〜4文で） | | |
| 5. 歴史的要素・史実との関連性は？ ヒント：国府、官道、継橋、行基の伝承 | | |
| 6. この物語の社会的評価・重要度は？ ヒント：だれが、いつ、どんな形で語りついできた？ | | |

**考えよう**：「伝承」と「史実」は、どこがちがうでしょう？ 1〜6のうち、確かめられることと、確かめられないことに分けてみましょう。

# 2. 歴史考証メモとデザイン画の作成

調べたことを、絵にできる形で書きとめます。わかったことの横に、小さなスケッチを描きましょう。

| 調べること | わかったこと（メモ） | スケッチ | 出典 |
| --- | --- | --- | --- |
| 1. 時代背景、自然、植生、地理（海岸線、入江、砂州、台地、川、生えている草木、生きもの） | | | |
| 2. 文化習俗、技術水準、建築様式、生活用具・漁具・農具（家のつくり、井戸、橋、舟、網、くわ、うつわ、機織り） | | | |
| 3. 男女の衣装（布の素材、織り方、染料、服の形）と装身具（身分の違いを表すもの） | | | |
| 4. 政治、宗教、産業（だれが治めていた？ 何をまつっていた？ 何をつくっていた？） | | | |
| 5. 人々の暮らし、家族の形、婚姻制度（だれと住む？ 結婚はどうやって申しこむ？） | | | |

**気をつけよう**：時代劇やまんがで見るすがた（例：烏帽子、ちょんまげ、着物の帯むすび）は、もっと後の時代のものかもしれません。

# 4. 「どんな人物（男性）」が手児奈への求婚者として想定され得るのだろうか？

2で調べた時代・土地・身分にいそうな人を考えます。1人につき1枚書きましょう。

## 求婚者カード

| 項目 | 考えたこと |
| --- | --- |
| 1. 身分・職業（どこから来た？ 何をしている人？） | |
| 2. 人物特性・表情（性格、くせ、得意なこと、手児奈への思い） | |
| 3. 服装・髪型・装身具（布の素材と色、服の形、髪、持ち物、身分を表すもの） | |
| 4. どんな演技・セリフで手児奈に求婚する？（求婚の決めポーズ、求婚の言葉、手児奈の断りの言葉、ことわられたときのポーズとひとこと） | |
