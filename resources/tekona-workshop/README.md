# 手児奈ワークショップ（40分）の素案

国府台地域（市川市真間）に伝わる「真間の手児奈」を、AIを使った参加型紙芝居として再話する40分ワークショップの教材素案です。
参加者はUSBカメラの前で手児奈に求婚する男たちになりきってポーズをキメ、AI紙芝居の手児奈に断られます。
メインは、参加者の提案から4人目の求婚者（キャラクター・決めポーズ・セリフ）をつくり、
参加者の協力でTeachable Machineのポーズ学習用の写真を撮影し、モデルを作って作品に加える部分です。

開催日・会場・対象年齢は未確定です。日付が決まったら、既存の`resources/20260801/`と同じく日付のディレクトリ名へ移し、
教材本文はdocsリポジトリ（`turbowarp-kamishibai-docs`の`docs/workshops/<日付>/`）へ移す想定です。

## ファイル

| ファイル | 対象 | 内容 |
| --- | --- | --- |
| [`tekona-workshop.md`](tekona-workshop.md) | 参加者 | 当日の流れ、求婚者づくりシート、決めポーズの注意、撮影のコツ、本来の言い伝えとまとめ |
| [`tekona-workshop-staff.md`](tekona-workshop-staff.md) | 進行役・スタッフ | 40分のタイムテーブル、役割、事前準備、作画・学習・台本書き換えの手順、トラブル対応、終了後の写真の破棄 |
| [`pose-dataset-plan.md`](pose-dataset-plan.md) | スタッフ | 事前に用意するポーズ学習用データ（`stand`／`heart`／`offer`／`wide`）の撮影計画と取り扱い |

作品（台本・立ち絵・ポーズ絵・背景）は[`stories/tekona/`](../../stories/tekona/README.md)にあります。

## 用意済みのもの

* 台本`stories/tekona/tekona.k4.yml`：DSL 4.0。求婚の場面は`forEach`で求婚者の一覧（表）を順に再生し、
  `if`で「手児奈の心がゆれたか」を分岐します。公開App 4.0.0-rc.79で検証済み。
* 手児奈（立ち絵・断る・決意）、求婚者3人（里の若者・国府の役人・都の貴族）の立ち絵とポーズ絵、4人目の仮の絵、背景4枚のSVG仮素材。

## まだ用意していないもの

* **ポーズ学習用データとモデル**：写真の撮影が必要です。[`pose-dataset-plan.md`](pose-dataset-plan.md)に従って事前撮影し、
  モデルの共有リンクを台本の`SuitorPoses`へ設定してください。写真を含む`project.tm`はこのリポジトリへコミットしません。
* **SB3とWeb版**：ワークショップ用（台本を外部から読み込む版）と公開用（台本を埋め込んだ版）のSB3、Web版、
  生成スクリプトとartifact lock、作品一覧への掲載。モデル完成後に作成します。
* 教材の図版（画面写真）、PDF化、配布ZIPの生成。
